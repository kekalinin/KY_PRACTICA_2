# KY_PRACTICA_2

CLI-инструмент визуализации графа зависимостей
для менеджера пакетов Python (pip).

## Общее описание

Инструмент строит граф транзитивных зависимостей
пакета, полученного из индекса PyPI, и сохраняет
его в виде изображения PNG через Mermaid.

## Параметры командной строки

| Параметр      | Описание                                   |
|---------------|--------------------------------------------|
| `--package`   | имя анализируемого пакета                  |
| `--repo`      | URL репозитория или путь к тестовому файлу |
| `--test-repo` | включить режим тестового репозитория       |
| `--output`    | имя файла с изображением графа             |
| `--max-depth` | максимальная глубина анализа               |
| `--filter`    | подстрока для фильтрации пакетов           |

## Сравнение с реальным менеджером пакетов

Порядок загрузки, вычисленный нашим инструментом, может отличаться
от порядка, который использует pip. Причины расхождений:

1. **Маркеры окружения.** PyPI указывает зависимости с условиями
   (`sys_platform == 'win32'`). pip учитывает эти условия, наш
   инструмент — нет.

2. **Необязательные зависимости (extras).** Зависимости с
   `extra == '...'` устанавливаются только при запросе конкретного
   extras. Мы их игнорируем.

3. **Уже установленные пакеты.** pip проверяет, что уже есть в
   окружении, и пропускает установку. Наш инструмент строит полный
   граф без учёта состояния системы.

4. **Выбор версий.** pip решает конфликты версий и может
   переставить порядок установки. Мы работаем только с именами
   пакетов, без версий.

5. **Кэширование и зеркала.** pip может использовать кэш или
   альтернативное зеркало, что влияет на порядок запросов.
